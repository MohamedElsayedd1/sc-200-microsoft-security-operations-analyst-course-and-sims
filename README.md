# SC-200 Microsoft Security Operations Analyst

A hands-on cybersecurity learning repository documenting my journey through the Microsoft SC-200 Security Operations Analyst curriculum.

The repository focuses on practical SOC operations using the Microsoft security ecosystem, including Microsoft Sentinel, Microsoft Defender XDR, Defender for Endpoint, KQL, threat hunting, detection engineering, incident investigation, and automated response.

## Topics Covered

- Microsoft Defender XDR
- Microsoft Defender for Endpoint
- Microsoft Sentinel
- Kusto Query Language (KQL)
- SIEM & XDR Operations
- Analytics Rules
- Custom Detections
- Incident Investigation
- Threat Hunting
- MITRE ATT&CK
- Threat Intelligence & Indicators
- Data Connectors & Data Collection Rules
- Syslog / CEF / Windows Security Events
- Automation Rules & Playbooks
- Defender for Office 365
- Defender for Cloud
- Defender for Cloud Apps
- Microsoft Purview & DLP
- Insider Risk Management
- Microsoft Security Copilot

## Goal

The goal of this repository is to move beyond theoretical knowledge and build practical skills required for a Junior SOC Analyst / Blue Team role, with an emphasis on the detection → investigation → response → remediation workflow.
